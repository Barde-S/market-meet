# Changelog

All notable changes to the MarketMate project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project structure setup
- Flutter mobile app scaffolding
- Node.js backend with Express.js
- Firebase integration (Auth, Firestore, Storage)
- Google Maps API integration setup
- User authentication system
- Agent profile management
- Booking system
- RESTful API endpoints
- Comprehensive documentation

### Mobile App Features
- Splash screen
- Authentication provider
- Agent discovery provider
- Booking management provider
- Agent and Booking data models
- Basic app configuration

### Backend Features
- Express.js server setup
- Firebase Admin SDK integration
- Authentication middleware
- Error handling middleware
- Winston logging system
- Rate limiting
- API routes:
  - `/api/auth` - Authentication endpoints
  - `/api/agents` - Agent management
  - `/api/bookings` - Booking management
  - `/api/users` - User profile management

- Firebase setup guide
- Google Maps setup guide

- Mobile app README
- Backend API README
- MIT License
